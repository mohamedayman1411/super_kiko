# Super Kiko – README

## Game Overview

Super Kiko is a simple 2D platformer game where you control a player and move across different platforms. The game includes energy cells that can be collected, moving platforms, and a portal that represents the entrance to the next level.

## Controls

- **A / D:** Move left and right.
- **S:** Move down through platforms.
- **Spacebar:** Jump.

## Collectables

Energy cells are placed around the level and can be collected by the player.

## Platforms

The game includes regular platforms and moving platforms that move up and down. You can also press **S** while standing on a platform to drop down through it.

## Portal

There is a portal at the end of the level that is intended to take the player to the next level, but it is currently only visual and does not work yet.
